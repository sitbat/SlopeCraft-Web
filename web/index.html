关于 SlopeCraft Web

SlopeCraft 是面向 Minecraft 地图的像素画生成器。网页版以原项目 C++ 算法为核心，通过 WebAssembly 在浏览器本地完成转化与导出。

原作：TokiNoBug 与 SlopeCraft 贡献者。软件遵循 GPL-3.0-or-later，保留原作者声明和许可证。

项目源码 ↗　GPL 许可证 ↗　原项目 ↗　使用文档 ↗

运行条件：HTTPS 或 localhost、安全上下文、跨源隔离与 SharedArrayBuffer。采用多线程引擎；当前环境不满足时会明确提示。

当前颜色表

每个格子的编号为 Minecraft 地图颜色 ID。斜线格表示当前颜色表未启用；下载 PNG 按 ID 位置输出原程序相同的 16 × 16 像素颜色表，未启用处透明。
